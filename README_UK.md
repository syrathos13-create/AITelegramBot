# RoBerT0 — інструкція із запуску бота

Цей документ пояснює, як запустити бота з нуля: що встановити, які файли заповнити і як його увімкнути.

## 1. Що потрібно встановити на комп'ютер

1. **Python 3.11 або новіший** — завантажити з [python.org](https://www.python.org/downloads/)
   - Під час встановлення на Windows обов'язково постав галочку **"Add Python to PATH"**
2. **VS Code** (або будь-який редактор коду) — [code.visualstudio.com](https://code.visualstudio.com/)

## 2. Встанови бібліотеки Python

Відкрий термінал у папці проєкту (в VS Code: `Terminal → New Terminal`) і виконай: 

*pip install -r requirements.txt*

Це встановить усі потрібні бібліотеки одразу:
- `python-telegram-bot[job-queue]` — робота з Telegram та планувальник нагадувань
- `google-genai` — підключення до нейромережі Gemini (текст, картинки, відео, голос)
- `Pillow` — генерація точних малюнків (команда `/draw`)
- `python-docx` — створення та редагування Word-документів
- `python-pptx` — створення та редагування PowerPoint-презентацій
- `openpyxl` — створення та редагування Excel-таблиць

## 3. Отримай ключі доступу

### Telegram Bot Token
1. У Telegram знайди `@BotFather`
2. Напиши `/newbot`, дай боту ім'я та юзернейм (має закінчуватись на `bot`)
3. BotFather надішле токен — довгий рядок виду `123456:ABC-def...`

### Gemini API Key
1. Зайди на [aistudio.google.com](https://aistudio.google.com)
2. Увійди через Google-акаунт
3. Натисни **Get API key → Create API key**
4. Скопіюй ключ

### Твій власний Telegram ID (щоб стати адміном бота)
1. Напиши боту `@userinfobot` у Telegram — він покаже твій ID (просто цифри)

## 4. Заповни `config.py`

Відкрий файл `config.py` в корені проєкту і встав свої дані:

```python
TELEGRAM_TOKEN = "твій_токен_від_BotFather"
GEMINI_API_KEY = "твій_ключ_від_Google_AI_Studio"
ADMIN_ID = "твій_telegram_id"
```

## 5. Заповни `system_prompt.txt`

Це текстовий файл (не код) з описом характеру бота — можна писати будь-якою мовою. Наприклад: 

*Тебе звати RoBerT0. Ти дружній бот-співрозмовник. Відповідай природно та коротко.*

## 6. Запусти бота

У терміналі, знаходячись у папці проєкту:

*python main.py*

Якщо в терміналі з'явився рядок **"RoBerT0 запущен..."** — бот працює. Перевір, написавши йому щось у Telegram.

## 7. Структура проєкту (для довідки)

robert0-bot/
├── main.py ← точка входу, запускати саме цей файл
├── config.py ← сюди вписуються ключі (крок 4)
├── system_prompt.txt ← характер бота (крок 5)
├── requirements.txt ← список бібліотек (крок 2)
├── profiles/ ← тут автоматично зберігається пам'ять про кожного користувача
├── group_prompts/ ← особливі промти для груп
├── data/ ← налаштування бота та індекс юзернеймів
├── core/ ← вся логіка бота (не потрібно редагувати вручну)
└── commands/ ← обробка команд (не потрібно редагувати вручну)

## 8. Основні команди після запуску

- `/help` — список усіх команд для звичайних користувачів
- `/admin_help` — список адмін-команд (видно лише тобі, власнику, за твоїм ADMIN_ID)
- `/language uk` — переключити мову команд на українську

## 9. Типові проблеми

**"ModuleNotFoundError"** — не встановлена якась бібліотека. Повтори крок 2 (`pip install -r requirements.txt`).

**Бот не відповідає взагалі** — перевір, чи правильно скопійований `TELEGRAM_TOKEN` в `config.py`, без зайвих пробілів.

**"429 RESOURCE_EXHAUSTED" в терміналі** — вичерпано безкоштовний денний ліміт Gemini API. Або зачекай до завтра, або підключи платний тариф на [aistudio.google.com](https://aistudio.google.com) (розділ Billing) — це дуже дешево для особистого використання.

**Бот перестав відповідати після перезапуску комп'ютера** — бот працює лише поки запущений `python main.py` у терміналі. Щоб він працював цілодобово, його потрібно розмістити на сервері (VPS), що працює постійно.
